# JARVIS

A local personal voice assistant with an Iron Man-inspired dashboard.

## Features

- Local AI responses using Ollama and Qwen3
- Spacebar activation
- macOS Daniel voice
- Google Calendar and Gmail read-only access
- Live weather, news and world time
- React and Vite dashboard
- Local-first design

## Requirements

- macOS
- Python 3.12
- Node.js and npm
- Ollama

## Privacy

Google credentials, authentication tokens, local models and virtual environments are excluded from Git.
